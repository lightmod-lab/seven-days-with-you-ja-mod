同梱ファイルの権利・ライセンス
================================

本MODに含まれるファイルごとの権利関係を示します（ゲームのグラフィック・音声・映像は
一切含みません）。

1. localization-string-tables-chinese(simplified)(zh)_assets_all.bundle（翻訳済み言語テーブル）
   - 開発元（RErevue_studio／LoveStoryProject）のゲームデータの表示文字列を、
     日本語訳に差し替えたデータです。訳文部分の作成者は本MOD作者です。
   - 本MODの条項（README.txt「再配布について」）：パッケージ全体の再配布・販売は
     改変の有無・無料有料を問わず禁止。個人利用・解析・デバッグは自由。

2. Assembly-CSharp.dll（改造版・ゲーム本体コード）
   - 開発元の著作権が残るゲーム本体ファイルに、「起動時に (1) のフォント準備コードを
     1回呼び出す」命令1行を追加した改造版です。追加以外の命令の変更・削除はありません。
   - 改造・同梱は個人利用・互換（日本語表示）目的の非公式改変であり、
     権利者から削除の要請があれば直ちに配布を停止します。
   - 復元は Steam の「ゲームファイルの整合性を確認」で行えます。

3. SevenDaysJaFontFix.dll ／ SevenDaysJaFontFix_charset.txt（自作ファイル）
   - 本MOD作者が作成したファイルです。charset.txt は翻訳で使う全文字の一覧
     （プレーンテキスト・1,428字）です。
   - 条項は (1) と同じ（再配布・販売禁止／個人利用・解析・デバッグは自由）。

4. 実行時依存物（OSS）について
   - 本MODは BepInEx 等の実行基盤を必要とせず、同梱もしていません。
   - 開発工程で Mono.Cecil（MIT ライセンス）を Assembly-CSharp.dll への命令追加に使用
     しましたが、そのファイル・生成物は本配布物に含まれません。
   - ゲーム内蔵の Unity・TextMeshPro 等 API を**実行時に利用**するだけで、
     それらのファイルは同梱していません（ゲーム同梱物がそのまま使われます）。

権利者様へ：本MODの公開に問題がある場合は、配布ページの GitHub Issue までご連絡ください。
異議なく速やかに公開を停止・削除します。
