君との七日間 — 日本語化MOD（非公式）  版1.0.0（2026-11-23）
==============================================================

対象ゲーム
----------
Steam「君との七日間」（appid 3946810、Steamの日本語ページでの正式表記）
※本MODは非公式です。Steamストアページは「日本語版は制作中」と明記しており、
  待てる方は公式日本語版を待つことをおすすめします（本MODはファン翻訳の品質です）。
  公式日本語版リリース後は「元に戻す方法」で本MODを消せば正式版に移行できます。

このMODの構成
--------------
【標準・推奨】1回貼り付け（言語表＋フォント調整・計4ファイル）
  下の導入手順どおり「導入ファイル」の中身をまとめて貼ると、これが入ります。
  セリフ・地の文・選択肢・名前タグ・回想（バックログ）・確認ダイアログ
  （「記憶を読み込みますか？」等。セーブは作中表現に合わせ「記憶」と表示）が
  すべて日本語になり、地の文のひらがなも完全に表示されます（実機検証済み）。
  仕組み：ゲーム起動時に自動で、ゲーム本体同梱と同じフォント（思源黑体
  ボールドの生フォント）から日本語フォントを作り、翻訳で使う全文字
  （1,428字）を一度だけ準備します。プレイ中の再生成は発生しません。
  ※タイトルメニューのボタン（重写此生／新的游戏 など）、SKIP/AUTO、
  設定画面（Config）の項目文字は言語テーブルに含まれないため、原文のまま
  です（仕様）。設定画面で出る確認ダイアログだけは日本語で表示されます。

【上級者向け】言語テーブル1ファイルだけ（ゲーム本体の Assembly-CSharp.dll を
  上書きしたくない場合）
  上の説明のうち、地の文のひらがなだけが空白になります（ゲーム同梱の太字
  フォントに日本語のひらがなが用意されていないため）。その他は同上です。

導入方法（貼り付けは1回）
--------------------------
1. ゲームを終了します。
2. Steamライブラリでゲームを右クリック → 管理 →「ローカルファイルを閲覧」を開く
   （SevenDaysLauncher.exe がある最上位フォルダです）。
3. 本フォルダの「導入ファイル」を開き、中に入っている game フォルダ1個だけ を
   その最上位にコピーします。
   「マージしますか？」→続行、「上書きしますか？」→差し替え で完了です。
   （導入ファイル フォルダごと貼ると階層が二重になるので注意）
4. ゲームを起動し、言語設定で「简体中文（簡体中文）」を選びます。
   （実機検証済み：冒頭の地の文「耳元で鳴っていた蜂の音が…」を含む
   全文が日本語で表示、名前タグ「俺」も正常。文字化け・欠字なし。
   既存セーブデータはそのまま継続できます。）

※ Assembly-CSharp.dll の上書きを避けたい場合（上級者）：
  導入ファイル の中の言語テーブル1ファイルだけを、同じ階層どおりに置く
  形でも動きます。ただし地の文行のひらがな部分が空白になります。

元に戻す方法
------------
1. Steamライブラリでゲームを右クリック → プロパティ → インストール済みファイル →
   「ゲームファイルの整合性を確認」を押します。
   上書きした2ファイル（言語テーブル・Assembly-CSharp.dll）は Steam 管理の下で
   純正データへ復元されます。
2. 追加した SevenDaysJaFontFix.dll と SevenDaysJaFontFix_charset.txt は
   Steam が管理しないため、Managed\ フォルダから手動で削除してください。

技術メモ（何をするものか）
--------------------------
・SevenDaysJaFontFix.dll は約9KBの小さな管理コードで、ゲーム起動時に
  「ゲーム自身が使っているフォントの生データ（思源黑体ボールド）」から
  TMP（TextMeshPro）用の日本語フォントを1回だけ作り、翻訳テキストに
  登場する全文字を焼き込んでから、各フォントの代替（fallback）一覧に
  登録します。ファイルの中身（charset.txt）は全文字が一覧できる
  プレーンテキストです。
・ゲームの Assembly-CSharp.dll は「起動時に上記コードを1回呼ぶ」
  命令が1行追加されただけです（Steamの整合性確認で純正版に戻せます）。
・翻訳はAI（LLM）が中国語原文から行い、原文との行数・タグ・伏線文字・
  用語の一貫性は機械検査で行単位に検証しています。

注意
----
・音声は中国語音声のまま再生されます（Steamストアページの表記でも
  日本語ボイスは未実装です。日本語音声ファイルはこのMODに含まれません）。
・Steam実績は公式13件があります。本MODは表示テキストとフォントのみを
  扱い、実績の判定コードは変更していません。MOD適用プレイ中にSteam実績が
  正常に解除されることを実機で確認済みです（2026-11-23）。
・ゲーム内の一部画像（タイトルロゴ等）に焼き込まれた文字は
  簡体中文版のままです。
・このMODを更新する際は、導入済みのファイルを同じ手順で上書きしてください。
